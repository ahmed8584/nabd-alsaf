## 📖 عن المنصة

**نبض الصف** هي منصة تعليمية ذكية تم تصميمها لمساعدة المعلم على تحويل الحصة التقليدية إلى تجربة تفاعلية، محفزة، وممتعة للطلاب. تعتمد المنصة على تصميم عصري (Glassmorphism) وتوفر أدوات متقدمة لإدارة الفصول، منح النقاط، وتحليل الأداء.

---

## ✨ الميزات الرئيسية

### 🏫 إدارة الفصول والطلاب
- إنشاء فصول متعددة والتبديل بينها بسهولة.
- إضافة الطلاب يدوياً أو استيرادهم من ملفات Excel/CSV.
- بطاقات طلابية تفاعلية مع أفاتار (صور رمزية) ومستويات تحفيزية.
- دعم فصلين دراسيين (ف1 / ف2) مع إمكانية التبديل بينهما.

### 🏆 نظام التحفيز والنقاط
- منح النقاط بناءً على معايير جاهزة (مشاركة، تعاون، إبداع... إلخ).
- إمكانية تحديد طالب واحد أو مجموعة طلاب ودفعة واحدة (Bulk).
- نقاط مخصصة وخصومات سريعة.
- تأثيرات بصرية (Confetti) وأصوات تشجيعية عند منح النقاط.

### 🎯 أدوات الحصة التفاعلية
- **العجلة العشوائية**: لاختيار طالب أو مجموعة باختيار عشوائي مع مؤثرات صوتية.
- **المؤقت**: وضع تنازلي وتصاعدي مع نغمات تنبيه.
- **المجموعات**: تقسيم عشوائي للطلاب وتوزيع أدوار قيادية داخل كل مجموعة.
- **إشارات الانتباه**: عرض إشارات بملء الشاشة (هدوء، استماع، انتهى الوقت...).

### 📊 التقارير والإحصائيات
- **لوحة الصدارة**: ترتيب الطلاب حسب النقاط مع شارات ذهبية وفضية وبرونزية.
- **مقارنة الفصلين**: رسوم بيانية تفاعلية (Chart.js) لمقارنة أداء الطلاب.
- **سجل النقاط**: تتبع كل عملية منح أو خصم مع الوقت والسبب.
- **تصدير**: إمكانية تصدير التقارير إلى Excel أو حفظها كصورة عالية الدقة.

### 🤖 المساعد الذكي
- مساعد تربوي مدعوم بالذكاء الاصطناعي (Google Gemini).
- توليد أسئلة، أفكار أنشطة، رسائل لأولياء الأمور.
- واجهة محادثة سلسة مع إمكانية نسخ الردود.

### 🎨 التصميم وتجربة المستخدم
- تصميم عصري زجاجي (Glassmorphism) متوافق مع جميع الأجهزة (Responsive).
- وضع ليلي/نهاري (Dark/Light Mode).
- إشعارات (Toasts) وتأثيرات حركية سلسة.
- دعم كامل للغة العربية (RTL).

## 🚀 كيفية الاستخدام (للمعلم)

1. **فتح المنصة**: قم بفتح الرابط في متصفح حديث.
2. **تسجيل الدخول**: أدخل كلمة المرور الافتراضية: `1234`.
3. **تغيير كلمة المرور**: اذهب إلى الإعدادات لتغيير كلمة المرور إلى كلمة سرية.
4. **اختيار الفصل**: اختر فصلاً من القائمة المنسدلة أو أنشئ فصلاً جديداً.
5. **إضافة الطلاب**: أضف أسماء طلابك أو استوردهم من ملف Excel.
6. **بدء التفاعل**: استخدم أدوات الحصة (العجلة، المؤقت) أو ابدأ بمنح النقاط.

---

## 🛠️ المتطلبات التقنية

- **المتصفح**: Chrome, Edge, Safari, أو Firefox (حديث).
- **الخادم**: Google Apps Script (خادم مجاني يعتمد على Google Sheets لقاعدة البيانات).
- **الاستضافة**: GitHub Pages (أو أي استضافة ثابتة).
- **المكتبات**: Chart.js, SheetJS (XLSX), html-to-image, Google Fonts.
